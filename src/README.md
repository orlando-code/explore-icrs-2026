# Source modules

| Package | Role |
|---------|------|
| `data_paths.py` | Canonical `data/` paths |
| `sources/` | Programme and delegate list loading |
| `registry/` | Person (`icrs-p-*`) and affiliation (`icrs-a-*`) registries; `key_resolution.py` for runtime identity |
| `geocoding/` | Geocode CSVs, Google API, overrides |
| `emissions/` | Travel emissions and `emissions-data.js` build |
| `geography/` | Country boundaries, neighbors, choropleth clusters |
| `site/` | Map/talks JS export helpers |
| `profiles/` | Speaker profiles and talk similarity (optional) |
